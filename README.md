# For Husna ♡

A one-page birthday invitation: sky-blue, cloudy, ivory and a little dreamy.
Plain HTML/CSS/JS, no build step.

## Preview
Open `index.html`, or run `python3 -m http.server` and visit http://localhost:8000.

## Personalise (`script.js`)
- `CONFIG.from` – the name in the signature.
- `CONFIG.date` – birthday date (6 Oct 2026) and countdown.

Edit times and notes straight in `index.html` (the `#plan` section). To fill the polaroids,
replace the icon inside a `.photo` div with `<img src="photos/yours.jpg" alt="">`.

## Deploy
GitHub Pages: Settings → Pages → deploy from branch, root folder.
